_# UI Test Automation | LUARA **(проект в разработке)**

Автоматизированный UI-фреймворк для тестирования интернет-магазина **LUARA**.

Проект разработан на **Python + Playwright + Pytest** с использованием архитектуры **Page Object Model (POM)**, компонентного подхода (**Page Components**), переиспользуемых UI-элементов(**Page Factory**), **Pydantic Settings**, **Allure Report** и **GitHub Actions CI**.

---

# О проекте

Проект создан в качестве портфолио для демонстрации навыков разработки современного UI automation framework.

На текущий момент реализованы:

- архитектура **Page Object Model (POM)**;
- компонентный подход (**Page Components**);
- переиспользуемые UI-элементы(**Page Factory**);
- параметризация тестов;
- набор Smoke, Regression;
- Allure Report (с приложенными видео, trace-файлами, logs);
- автоматический запуск тестов в GitHub Actions.

---

# Используемые технологии

- Python 3.12
- Playwright
- Pytest, pytest-xdist
- Pydantic Settings
- Allure Report
- GitHub Actions
---
# Реализованные сценарии тестирования

На текущий момент проект включает более **50 автоматизированных UI-тестов**, покрывающих основные пользовательские сценарии интернет-магазина **LUARA**.

Реализованы сценарии тестирования:
- Авторизация;
- Главная страница;
- Каталог;
- Сортировка каталога;
- Карточка товара;
- Корзина;
- Поиск;
- Header.


# Что демонстрирует проект

Проект демонстрирует практический опыт разработки UI automation framework и применения современных подходов к автоматизации тестирования, включая:
- построение масштабируемого UI automation framework.
- проектирование архитектуры Page Object Model (POM);
- использование компонентного подхода (Page Components); разработку переиспользуемых UI-элементов;
- написание стабильных и поддерживаемых UI-тестов;
- параметризацию тестовых сценариев;
- работу с Playwright и Pytest;
- конфигурацию проекта с использованием Pydantic Settings;
- формирование Allure-отчетов с вложениями (видео, trace, logs) и Allure History;
- настройку CI с использованием GitHub Actions;
- работу с Git и GitHub.
